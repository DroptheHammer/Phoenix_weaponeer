# Phoenix Weaponeer

A desktop attack planner for DCS World squadrons. Import a mission, lay out
the threats, plan each jet's attack geometry and weapons, and export
kneeboard cards ready to drop into DCS.

## Download

Get the installer for Windows, macOS or Linux from the
[latest release](https://github.com/DroptheHammer/Phoenix_weaponeer/releases/latest).
See [docs/INSTALLING.md](docs/INSTALLING.md) for install notes.
