# Phoenix Weaponeer

A desktop attack planner for DCS World squadrons. Import a mission, lay out
the threats, plan each jet's attack geometry and weapons, and export
kneeboard cards ready to drop into DCS.

## Download

Get the installer for Windows, macOS or Linux from the
[latest release](https://github.com/DroptheHammer/Phoenix_weaponeer/releases/latest).
See [docs/INSTALLING.md](docs/INSTALLING.md) for install notes.

## Credits

The app's About dialog (File, then About) lists every source it draws on.
The sight figures on manual bomb cards come from these:

- *F-5E Bomb And Rocket Depression Tables For Kneeboard* (DCS User Files
  no. 3320266; the pack names no author)
- *F-4E Kneeboards* and *Mirage F1 Kneeboards* by AKA_Relent (DCS User Files
  nos. 3338073 and 3329090)
- the *A-4E Community for DCS World, Kneeboard Manual*, version 2.3, by the
  A-4E Community mod team

The app prints their figures where an attack matches a printed point and
works its own estimates around them, marked "est.". The authors have not
checked the app's estimates.
